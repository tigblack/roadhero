# Инструкции для агентов — RoadGame

Описание игры, кода и автотестов: `README_RoadGame.md`.

## Game-dev навыки проекта

Установлены 79 специализированных навыков и роутер из `gamedev-skills/awesome-gamedev-agent-skills`. Каталог, закреплённая ревизия и лицензия: `.agents/gamedev-library/README.md`; навыки: `.agents/skills/`.

- Для новой игровой задачи, если навыки ещё не выбраны, прочитать `.agents/skills/router/SKILL.md` и выбрать только нужные навыки. Не загружать всю библиотеку одновременно.
- Это Unity-проект: версию читать из `ProjectSettings/ProjectVersion.txt`. Сохранять текущую версию и архитектуру; примеры навыков сверять с установленными API. Веб-оболочка в `Sites/` не меняет движок игры.
- Исходные пути библиотеки `skills/<category>/<name>/SKILL.md` соответствуют локальным `.agents/skills/<name>/SKILL.md`. Справочники и скрипты лежат внутри папки навыка; скрипты вызывать по полному установленному пути.
- Правила проекта и запрос пользователя определяют применение примеров. К Unity batch-командам из навыков всегда добавлять `-disableaudio`; тестовые браузерные вкладки открывать с `?mute`. Остальные правила тишины ниже сохраняются.
- Установка навыков сама по себе не разрешает обновлять движок, массово перезаписывать ассеты или публиковать игру. Для этого нужна соответствующая задача пользователя.

## Рабочие и тестовые запуски — всегда без звука

Любой запуск проекта для работы или проверки идёт полностью беззвучно: музыка, двигатель, выстрелы, интерфейс, все эффекты. Звук отключается до первого воспроизведения.

- **Unity Editor.** `Assets/RoadGame/Editor/WorkAudioMute.cs` выключает мастер-звук редактора (`EditorUtility.audioMasterMute`):
  - при загрузке редактора — это покрывает batch-прогоны, автотесты и предпросмотры;
  - перед каждым входом в Play Mode и сразу после него.

  Скрипт не удалять и не обходить. В batch-режиме он включён всегда. Пользователь может выключить его для себя: меню **RoadGame → Audio → Mute Work Runs**.
- **Batch-запуски Unity** (`-batchmode`, `AutoCapture`, сборки) — дополнительно добавлять флаг `-disableaudio`: FMOD стартует без вывода звука.
- **Браузер / WebGL.** Шаблон `Assets/WebGLTemplates/RoadGame/index.html` глушит вкладку ещё до запуска Unity:
  - если в адресе есть `?mute` (или `#mute`);
  - если эта вкладка уже открывалась с `?mute` — флаг хранится в `sessionStorage` и переживает перезагрузки;
  - если браузер управляется автоматически (`navigator.webdriver`).

  Тестовые вкладки открывать как `.../index.html?mute`. Chrome для тестов запускать с `--mute-audio` и отдельным временным профилем (`--user-data-dir`). `?mute=0` снимает отключение звука в этой вкладке.
- **Чего не делать:**
  - не трогать системную громкость компьютера;
  - не переключать игровые настройки Sound и Music ради тишины: они сохраняются в сейв игрока.

  Готовая игра (APK, WebGL без `?mute`, macOS) звучит как обычно и уважает настройки игрока.

## Чужие изменения

В проекте работают и другие агенты, например сборка WebGL в `Sites/roadgame-webgl/dist`. Перед записью файла проверить, не менялся ли он после начала работы, и не перезаписывать чужие правки.

## Иконки интерфейса

Иконки — запечённые рендеры 3D-моделей:
- модели — `Assets/RoadGame/Editor/Icons/IconModels.cs`;
- студия рендера — `IconStudio.cs`;
- результат — `Assets/RoadGame/Resources/Icons/*.png`.

После правки моделей пересобрать иконки: меню **RoadGame → Icons → Bake UI Icons** или batch `-executeMethod RoadGame.EditorTools.IconStudio.BakeBatch`. Рисовать иконки в рантайме не нужно: `Tex.Get(Icon)` только загружает спрайты.
