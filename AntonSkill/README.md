# AntonSkill — разбор геймплея игр «как Антон»

Скилл для Claude Code. Смотрит геймплейный ролик игры и пишет фидбек по советам Антона из разборов FlipTheCoin и CatMiners: что не так, как поправить, что сделано хорошо и стоит забрать себе. С моментами ролика и дословными цитатами Антона.

## Установка

1. Скопируй папку `anton-gameplay` в `~/.claude/skills/` (Windows: `%USERPROFILE%\.claude\skills\`), тогда скилл работает во всех проектах. Можно и в `.claude/skills/` внутри одного проекта.
2. Поставь программы:
   - Python 3.10+ и пакеты: `python -m pip install -U yt-dlp pillow numpy`;
   - ffmpeg 5.1+ в PATH: Windows — `winget install Gyan.FFmpeg`, macOS — `brew install ffmpeg`, Linux — пакет `ffmpeg`;
   - Node.js или Deno: yt-dlp нужен JS-движок для YouTube.
3. Перезапусти Claude Code.

## Как пользоваться

Напиши в Claude Code, например:
- «разбери геймплей Royal Match как Антон»;
- «что Антон скажет про эту игру: <ссылка на ролик или стор>»;
- можно приложить скриншоты.

Результат появится в папке `_anton/<игра>/` текущего проекта: листы кадров, отдельные кадры и отчёт `РАЗБОР.md`.

## Что внутри

- `SKILL.md` — инструкция для Claude;
- `scripts/grab.py` — поиск ролика, скачивание и нарезка кадров (yt-dlp + ffmpeg);
- `scripts/check_quotes.py` — сверка цитат Антона в отчёте с конспектами;
- `references/checklist.md` — правила Антона в 12 разделах, с цитатами;
- `references/report.md` — шаблон отчёта;
- `references/СОВЕТЫ_АНТОНА.md`, `references/UX_СОВЕТЫ_АНТОНА.md` — конспекты разбора, по ним сверяются цитаты.

CatMiners: 33 карточки первичного источника с контекстом, аудиофрагментами и видеопроверкой говорящего. Прежний редакторский список 16 общих правил заменён; метод и пределы машинной проверки описаны в материалах.
