# Враги третьей зоны «Пепельная зима» (Ashen Winter)

Враги и босс третьей зоны (индекс 2, бывшая SALT FLATS) заменены семью существами по концепт-листу
`Concepts/AshenWinter_Enemies_Concept_v1_2026-11-25.png`. Каждое смоделировано заново по формам листа (не перекраска старых моделей), у каждого своя схема суставов и свой процедурный аниматор в Unity.

Логика игры не изменилась: прежние ModelId, постоянные ID спавнов, здоровье, урон, интервалы, подготовка удара, способ атаки (снаряд или ближний бой), агро, награды и респаун. Меняется только тело и то, откуда и как видна атака.

## Файлы

| Путь | Что это |

| `AshenWinter_Enemies_v1.blend` | Редактируемая сцена: коллекция на каждое существо (`01_AshPecker (Scav)` … `07_BlackReactor (BossColossus)`), корневой пустой объект и жёсткие части в своих суставах, скрытые копии LOD1 под тяжёлыми частями |
| `scripts/` | Скрипты полной сборки, экспорта и рендеров (ниже) |
| `textures/T_AshenEnemies_BaseMap_1K.png` | Общий атлас существ: 16 полос (бетон, пепел, перо, шкура, кабель, ржавчина, металл, снег, полосы опасности, протектор, ткань, кость, лёд, решётка, панель) |
| `renders/` | Рендеры спереди, сбоку, сзади, в 3/4, с угла концепта и с угла игровой камеры; листы сравнения с концептом и кадрами Unity |
| `Concepts/` | Концепт-лист и его промпт |

В игре:
- бандл `Assets/RoadGame/Resources/Creatures/AshenWinterEnemies/` (`manifest.json`, `Meshes/*.bytes`, атлас, `export_report.json`);
- код `Assets/RoadGame/Scripts/World/Mutants.cs` (общий загрузчик бандлов существ по зонам) и `Assets/RoadGame/Scripts/World/AshenEnemies.cs` (семь аниматоров).

## Сборка

```sh
B=/Applications/Blender.app/Contents/MacOS/Blender
cd ArtSource/Characters/AshenWinterEnemies/scripts
# 1. атлас (запускается сам, если файла нет)
python3 aw_enemy_tex.py ../textures
# 2. сцена: модели, AO в цвете вершин, LOD1 (около 3 секунд)
$B -b --factory-startup --python aw_build.py -- --out ../AshenWinter_Enemies_v1.blend
# 3. бандл для Unity (из корня проекта)
cd ../../../..
$B -b ArtSource/Characters/AshenWinterEnemies/AshenWinter_Enemies_v1.blend \
   --python ArtSource/Characters/AshenWinterEnemies/scripts/aw_export.py -- \
   --output Assets/RoadGame/Resources/Creatures/AshenWinterEnemies
# 4. рендеры (front, side, back, three, concept, game) и силуэты
$B -b ArtSource/Characters/AshenWinterEnemies/AshenWinter_Enemies_v1.blend \
   --python ArtSource/Characters/AshenWinterEnemies/scripts/aw_render.py -- --out <папка> --res 768 --silhouettes
```

Отдельное существо для быстрой проверки: `aw_build.py -- --out <файл> --only pecker --render <папка> --views concept,side`.
Сборка детерминирована: повторная сборка даёт те же треугольники и меши.

Blender в режиме `-b` звука не выводит; Unity для проверок запускается только с `-disableaudio`.

| Скрипт | Что делает |
|---|---|
| `aw_lib.py` | Набор поверх библиотеки болотных мутантов (`mut_lib`, `tw_lib`): палитра, атлас, бетонные плиты со сколами, снежные «подушки», клинки, кабели, арматура, кольца, гусеницы; `mirror_x` (сторона асимметричных частей как на листе) |
| `aw_enemy_tex.py` | Атлас существ |
| `aw_creatures.py` | Семь существ: массы, части в суставах, цвета, точки выстрела `Muzzle` |
| `aw_build.py` | Собирает `.blend`: модели, отражение, AO, LOD1 |
| `aw_export.py` | Бандл в формате бандлов мутантов (`mut_export.py`): 14 float на вершину, оси Unity, обратный порядок вершин |
| `aw_render.py` | Презентационные рендеры, в том числе с угла концепт-листа (`CONCEPT_VIEW`) |

## Как устроены модели

- **Части в суставах.** Имена частей — договор с аниматором:
  - клювач: `Body`, `WingL/R`, `Neck` → `Head` → `Muzzle`, `LegL/R` → `FootL/R`;
  - резак: `Body`, `Head`, `ForeL/R` → `BladeL/R`, `ThighL/R` → `ShinL/R`, `Tail`;
  - игольщик: `Body`, `Launcher` → `Muzzle`, `LegA/B/C` → `ShinA/B/C`;
  - котельник: `Body`, `Fire` (топка), `Pipe` → `Muzzle`, `LegFL/FR/BL/BR` → `Foot…`;
  - палач: `Pelvis` → `Torso` → `Head`, `ArmGun` → `Muzzle`, `ArmL` → `HandL`, `ThighL/R` → `ShinL/R`;
  - метельщик: `Body`, `TrackL/R`, `SkiL/R`, `WheelL0…4/R0…4`, `SprocketL/R`, `IdlerL/R`, `Turret` → `Gun` → `Barrels` → `Muzzle`, `Driver` → `DriverHead`;
  - реактор: `Pelvis` → `Torso` → `Head`, `Port` (ядро), `ArmHeavy` → `ForeHeavy` (кулак), `ArmClaw` → `ForeClaw` → `HandClaw`, `ThighL/R` → `ShinL/R`.
- **Материал.** Один toon-материал и общий атлас. Цвет в вершинах; альфа меньше 1 — самосвечение (глаза, топка котельника, ядро реактора). Блеск и металличность в UV1, AO запечён в цвет вершин.
- **Палитра по описанию:** грязно-белый снег, графитовые тела, серо-синие тени, приглушённая ржавчина и полосы опасности; янтарное свечение только в ядрах, топках и глазах.
- **LOD0, треугольников:** клювач 18,9 тыс., резак 19,8 тыс., игольщик 12,6 тыс., котельник 14,5 тыс., палач 21,4 тыс., метельщик 20,5 тыс., реактор 52,0 тыс. LOD1 — около половины. В игре LOD0 до 4,5 % высоты экрана.

## Unity

- **`Mutants.Apply`** работает для любой зоны со своим бандлом: зона 1 — болотные мутанты, зона 2 — эти существа. Сгенерированный гуманоид или багги удаляется целиком, существо строится из бандла, `Rig` переводится на новые части (тело, точка выстрела, высота полосы HP), добавляются `ImportedActorSurface` (мигание и почернение) и аниматор.
- **Аниматоры** (`AshenEnemies.cs`): покой, походка, подготовка по `Enemy.AnimWindup`, удар или выстрел точно в кадр урона, отдача, попадание, смерть.
  - клювач: шея выбрасывает голову-дуло, крылья вздрагивают при выстреле;
  - резак: вес на передних клинках, удар клинком из-за плеча;
  - игольщик: три ноги шагают по одной, корпус замирает, установка сама наводится на машину, игла вылетает из направляющей, отдача;
  - котельник: котёл раскачивается на ходу, топка разгорается при подготовке, труба наводится и отдаёт при навесном выстреле;
  - палач: перед выстрелом корпус поворачивается к машине и пушка замирает, отдача уходит в плечо и всё тело;
  - метельщик: гусеницы прокручиваются текстурой (`_BaseMap_ST`), катки вращаются, лыжи поворачивают, турель следит за машиной, стволы крутятся;
  - реактор: шаги с пылью и тряской, кулак поднимается к удару по площади и обрушивается в кадр урона, ядро пульсирует.
- **Высоты полос HP** (`Content.AshenStyle`): 1,85 / 2,25 / 3,1 / 2,55 / 3,7 / 2,8 м, босс 9,6 м. Радиусы прежние: они участвуют в генерации мира и постоянных ID спавнов.
- **Имена:** Ash Pecker, Snow Reaper, Needle Walker, Boiler Spitter, Concrete Executioner, Whiteout Raider; босс BLACK REACTOR («РЕАКТОР» в интерфейсе, цель «Победи ЧЁРНЫЙ РЕАКТОР»). Награды за босса прежние: Thunder Lance, Roof Plates, 200 самоцветов за первую победу, доступ к четвёртому региону.
- **Проверка** — сценарий `ashen` (`Editor/AutoCaptureMutants.cs` в режиме зоны 2): строение, точки выстрела, удары и кадр урона, мигание, смерть, гарпун, респаун, награды босса; 120 проверок. Результаты и кадры — `Docs/screenshots/ashen-winter-2026-11-25/`.

## Ограничения

- Лыжи метельщика, клинки резака и кулак реактора шире логического радиуса врага: у стен и камней они могут визуально заходить в декор. Радиус не увеличен намеренно.
- Смерть быстро прерывает гарпун, поэтому анимации смерти короткие.
- Старые сгенерированные меши врагов третьей зоны остались в снимке уровня, но в игре больше не создаются.
