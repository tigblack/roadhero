# Ashen Winter — третья зона (бывшая SALT FLATS)

Третья зона RoadGame (индекс 2) переделана в регион «Пепельная зима» по концепт-листу
`Concepts/AshenWinter_Environment_Concept_v1_2026-11-25.png` и описанию `AshenWinter_ArtDirection_v1_2026-11-25.txt`:
широкая тёмная S-дорога ведёт через выгоревшую снежно-пепельную долину к поднятой круглой арене у руин АЭС.

Вся художественная работа сделана в Blender скриптами из `scripts/`; сборка воспроизводима из копии снимка v10.
Число зон, постоянные ID спавнов, ModelId, баланс, респаун, награды и сохранения не менялись.
Враги и босс зоны — отдельная работа: `ArtSource/Characters/AshenWinterEnemies/`.

## Сборка

Нужен Blender 5.2. Команды выполняются из корня проекта.

```zsh
B=/Applications/Blender.app/Contents/MacOS/Blender
ART=ArtSource/Levels/AshenWinter
PY=/Applications/Blender.app/Contents/Resources/5.2/python/bin/python3.13   # numpy есть во встроенном Python Blender

# 1. Раскладка (структуры, запретные зоны для генератора, овраг) и текстуры
$PY $ART/scripts/awl_layout.py Exports/Blender/2026-11-17/scene.json $ART/data
cp $ART/data/AshenWinter_layout.json $ART/data/AshenWinter_surfaces.bytes Assets/RoadGame/Resources/Levels/
$PY $ART/scripts/awl_tex.py $ART/textures

# 2. Только если менялась раскладка: дороги и спавны мира с этой раскладкой (в копии проекта, без звука)
Unity -batchmode -disableaudio -nographics -quit -projectPath <копия проекта> \
      -executeMethod RoadGame.EditorTools.LevelBlenderExport.Run -exportOut <папка> -ashenLayout
#    из <папка>/scene.json в data/AshenWinter_world.json переносятся roads, spawns зоны 2, floors и keepouts

# 3. База из копии снимка -> сборка -> итоговая .blend
$B -b $ART/source/RoadGame_AllZones_v10_source_copy.blend --python $ART/scripts/awl_base.py -- --out /tmp/aw_base.blend
$B -b /tmp/aw_base.blend --python $ART/scripts/awl_build.py -- --out /tmp/aw_build.blend
$B -b /tmp/aw_build.blend --python $ART/scripts/awl_finalize.py -- $ART/AshenWinter_Zone02_v1.blend

# 4. Экспорт в Unity (выход обязательно внутри Resources: иначе в манифест попадут абсолютные пути)
$B -b $ART/AshenWinter_Zone02_v1.blend --python $ART/scripts/awl_export.py -- \
   --source-scene Exports/Blender/2026-11-17/scene.json --output Assets/RoadGame/Resources/Levels/AshenWinterZ2

# 5. Рендеры: ракурсы концепта (overview, ramp, bunker, arena, …) и игровой камеры
$B -b $ART/AshenWinter_Zone02_v1.blend --python $ART/scripts/awl_render.py -- --out $ART/renders --res 1280
```

Шаги 3–4 занимают около трёх минут на Apple Silicon. Шаги `awl_build.py` (по умолчанию все): `hide, props, terrain, roads, structures, bunker, arena, jump, landmarks, borders, scatter, devspawns, lod`.

Blender в фоновом режиме звука не выводит. Unity для проверок запускать только с `-disableaudio` (см. `AGENTS.md`).

| Скрипт | Что делает |
|---|---|
| `awl_layout.py` | Раскладка: арена, пандусы, бункер, трамплин, площадка, овраг, ориентиры; запретные прямоугольники; проверка, что ни одна структура не ложится на дорогу |
| `aw_texkit.py`, `awl_tex.py` | Текстуры: трим-атлас и земля |
| `awl_lib.py` | Набор для моделирования поверх наборов врагов и болот: плиты, снежные подушки, барьеры, фонари, деревья, скалы, наносы, остовы, опоры ЛЭП и провода, градирня, труба, цех, рёбра арены, виадук |
| `awl_base.py` | База: только третья зона снимка (без `Cliff.016/.017` — их держит вторая зона), меши отвязаны (`AW_`) |
| `awl_props.py` | Новые формы разрушаемых объектов зоны (13 видов, по 1–3 варианта) |
| `awl_terrain.py` | Земля тайлами 25 м с цветом в вершинах, отвалы бункера |
| `awl_world.py` | Дороги, структуры, бункер, арена, трамплин, ориентиры, массивы по краям, разброс декора, DEV-точка |
| `awl_build.py`, `awl_finalize.py` | Сборка по шагам, LOD1/LOD2 тяжёлых мешей, итоговый файл |
| `awl_export.py` | Бандл: только то, что изменено этим проходом (новые и перекрашенные объекты, скрытые оригиналы, прокси коллизий) |
| `awl_render.py` | Презентационные рендеры |

## Unity

- **Третий бандл.** `ImportedLevel` подключает бандл к индексу 2: реестр, `ForZone`, `ApplyTarget` (существа — через `Mutants.Apply`), сброс статики, материалы, обе ветки загрузки (обычная и WebGL с освобождением исходных данных). Исходная иерархия снимается один раз. Все 717 узлов снимка находят свои ID (`unmapped=0`).
- **Шов с болотами.** Южные скалы `Cliff.016/.017` (`node_000701/703`) и насыпи до z ≈ 305,6 принадлежат второй зоне; в бандле третьей их нет.
- **Поверхности** (`AshenSurfaces`). Те же числа, что в Blender:
  - платформа арены — пол на высоте 1,2 м, два пандуса с плавным профилем, грань-уступ по краю и парапет (в проёмах пандусов их нет);
  - трамплин — стартовый пол с разгоном; овраг — сетка высот;
  - всё это попадает в `Ground.Sample`, `NavGrid` и физику; бункер — коллайдеры из бандла, крыша зарегистрирована в `OcclusionFader`.
- **Спавны.** Запретные прямоугольники раскладки уходят в `Structures.Exclusions`. Генератор сдвигает только те спавны, что стояли в новых структурах (в игре 15, ID и награды прежние); босс стоит на платформе.
- **Текстуры** бандла импортируются как у остальных Blender-бандлов (`Editor/ImportedLevelTextureSettings.cs`: трилинейная фильтрация, мип-уровни, сжатие).
- **Подписи.** Зона ASHEN WINTER, «The Black Reactor's burnt valley», палитра, миникарта (контуры арены, бункера, трамплина), цели и подсказки.

Проверка — сценарий `ashenlevel` (`Editor/AutoCaptureAshen.cs`): бандлы и ID, поверхности, спавны, площадка ремонта, затухание крыши. Пять настоящих проездов: трамплин через овраг, тоннель, арена вверх и вниз, парапет, грань платформы. Результаты и кадры — `Docs/screenshots/ashen-winter-2026-11-25/`.

## Бюджет

Бандл: около 425 тыс. треугольников, 395 уникальных мешей, 84 прокси коллизий, 23,7 МБ. LOD1/LOD2 для градирни, цеха, массивов, отвала бункера, виадука, опор ЛЭП, стены арены, рощ, трубы и трубопроводов.

## Ограничения

- Рёбра арены, провода ЛЭП и пролёты виадука декоративные: коллайдеры только у оснований рёбер, опор ЛЭП и опор виадука.
- Свечение проёма цеха и фонарей — самосвечение в цвете вершин, без источников света (как в остальных зонах).
