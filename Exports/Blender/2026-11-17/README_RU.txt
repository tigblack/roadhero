RoadGame / Scarbound v10 — уровень для редактирования в Blender
Экспорт: 17 ноября 2026. Проверен в Blender 5.2.2 LTS.

С ЧЕГО НАЧАТЬ
Открой DustFlats_Level_v10.blend через File > Open в Blender.
В нём первая зона Dust Flats, вступительный каньон, трамплины,
подземный комплекс Mammoth Works, окружение, объекты спавнов
и машина в коллекции References для проверки масштаба.

RoadGame_AllZones_v10.blend содержит весь мир: четыре зоны и вступление.
FBX-версии лежат рядом; их открывают через File > Import > FBX.
Для работы в Blender предпочтителен .blend: в нём сохранены коллекции,
узловые материалы, цвета вершин, текстуры и заметки.

КАК РЕДАКТИРОВАТЬ
- Один Blender unit = один метр. Вертикальная ось — Z.
- Геометрия разделена на объекты. Иерархия исходного уровня сохранена.
- Коллекции Zone_00..Zone_03 разделяют зоны, References содержит машину.
- Подколлекции Roofs можно выключить глазом, чтобы видеть подземные помещения.
- Включи Material Preview (сфера в правом верхнем углу 3D View), чтобы видеть цвета.
- Объект из мира может использовать общий mesh с другими копиями. Для правки
  только одной копии выбери Object > Relations > Make Single User > Object & Data.
- Сохраняй свою рабочую версию отдельным .blend, чтобы следующий экспорт её не заменил.
- В текстовом редакторе Blender есть START HERE — RoadGame level с деталями экспорта.

ЧТО ПЕРЕНЕСЕНО
Статическая геометрия, props, статичные визуальные копии врагов и боссов,
названия, локальная иерархия и трансформации, цвета вершин, UV0/UV1, нормали,
материалы и упакованные текстуры. Оригинальная геометрия Unity и метаданные
поверхностей, спавнов и маршрутов сохранены в scene.json.

Материалы Blender воспроизводят цвета и текстуры, но приблизительно заменяют
специальный Unity-шейдер. Свет, тени, пыль и прозрачность крыш могут отличаться.
Из полного мира удалены 9148 треугольников нулевой площади: видимая геометрия
и все 919950 исходных вершин сохранены. Это предотвращает сбой Blender при импорте нормалей.

ГРАНИЦЫ ЭКСПОРТА
Это снимок уровня для моделирования и расстановки. Игровые скрипты, движение,
коллизии, аналитические поверхности Ground, ИИ, награды и сохранения здесь не работают.
Изменение .blend пока автоматически не меняет игру. Для возвращения правок
потребуется подключить обновлённую геометрию и согласовать поверхности,
коллизии, точки появления и маршруты в Unity.

ПРОВЕРКА
Оба .blend повторно открыты в Blender. Число вершин, граней после удаления
нулевых треугольников, UV/цвета и габариты сверены с исходным экспортом.
Результаты: validation.json и RoadGame_AllZones_v10.import-report.json.
Все рабочие запуски проведены без звука. Сохранение игрока не использовалось.
