# Roadhero / Scarbound

Полный Unity-проект аркадной автомобильной idle RPG: код, игровые ассеты, редактируемые Blender-исходники, музыка, документация, инструменты и навыки для ИИ-агентов.

Актуальная WebGL-сборка: **2026-11-26-car-feel**. В ней три оформленных региона, DEV-переходы между локациями и обновлённое более отзывчивое управление машиной.

- [Скачать готовую WebGL-сборку](https://github.com/tigblack/roadhero/releases/tag/webgl-2026-11-26-car-feel).
- [Подробное описание проекта и проверок](README_RoadGame.md).
- [Правила работы агентов и запусков без звука](AGENTS.md).

## Открыть проект

Нужны Git LFS и **Unity 6000.6.4f1** с модулем Web Build Support для сборки WebGL.

```sh
git lfs install
git clone https://github.com/tigblack/roadhero.git
cd roadhero
git lfs pull
```

Добавьте эту папку в Unity Hub и откройте указанной версией редактора. Дождитесь первого импорта. `Library` создаётся автоматически.

Крупные модели, аудио, бинарные ресурсы и WebGL-файлы хранятся через Git LFS. Для работы используйте клонирование с Git LFS, чтобы получить сами файлы.

## Готовая WebGL-версия

Текущий готовый плеер находится в `WebGLBuild/`. Для локального запуска:

```sh
python3 -m http.server 8000 --directory WebGLBuild
```

Откройте `http://localhost:8000/?mute` для беззвучной проверки или адрес без `?mute` для обычной игры. Запуск через `file://` не поддерживается. GitHub показывает файлы репозитория; скачанную игру нужно обслуживать HTTP-сервером.

В игре: **DEV → Локации → Зона 3 — Пепельная зима** для немедленной проверки нового региона. DEV также содержит скорость 1×/2×/4× и John Wick.

Повторная сборка на macOS:

```sh
bash Tools/build-webgl.sh "$PWD/Builds/WebGL/local-raw"
python3 Tools/WebGL/package_for_sites.py Builds/WebGL/local-raw Builds/WebGL/local-static --version local
```

Папка результата упаковки должна быть новой. На другой машине задайте `UNITY_EDITOR_PATH` на исполняемый файл той же версии Unity.

## Что включено

| Каталог | Содержимое |
| --- | --- |
| `Assets`, `Packages`, `ProjectSettings` | Полный открываемый Unity-проект с `.meta` и настройками |
| `ArtSource` | Blender-сцены, концепты, текстуры, музыка и скрипты создания |
| `ArtSource/ImportedMasters` | Перенесённые внешние исходники первой локации и машины с зависимостями |
| `Exports` | Исходные экспорты сцены и моделей, данные повторного импорта |
| `Tools` | Сборка, экспорт из Blender, генерация музыки и проверки |
| `Docs`, `ArtDirectionScreenshots`, `_anton` | Документация, кадры и отчёты проверки |
| `.agents`, `AntonSkill` | Проектные навыки, библиотека и её лицензии |
| `WebGLBuild` | Последняя готовая статическая WebGL-сборка |

В [описании ImportedMasters](ArtSource/ImportedMasters/README.md) указаны происхождение моделей, сохранённые зависимости и сопоставление старых абсолютных путей.

Кеши Unity, временные файлы, настройки пользователя, старые сборки и отдельный рабочий checkout ChatGPT Sites в репозиторий не включаются. Веб-шаблон игры находится в `Assets/WebGLTemplates/RoadGame`; текущий готовый плеер — в `WebGLBuild`.

Лицензия библиотеки навыков и уведомления об источниках сохранены в `.agents/gamedev-library/`. Исторические проверки и ограничения тестирования описаны в `README_RoadGame.md` и соответствующих отчётах `Docs/`.
